Python 3.9 standard library files, reduced for Xi Lite, from the a-Shell precompiled CPython distribution (https://github.com/holzschu/a-shell/releases/tag/cpython_05_22). The interpreter framework is python3_ios, built from CPython and linked with ios_system. Third-party site-packages, tests, and optional native extension frameworks are intentionally not included.
